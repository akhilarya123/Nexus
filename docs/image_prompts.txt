HOW TO USE THESE IMAGES
================================================================================

1. Generate each image using the prompt above (Midjourney, DALL-E 3, etc.)
2. Save with the exact filename specified (e.g. architecture.png)
3. Place all images in the docs/ folder of the project
4. The README.md already has the correct image references pointing to docs/
5. Recommended dimensions are provided but any reasonable aspect ratio works

STYLE CONSISTENCY TIPS:
- Always use #0d1117 as background (matches GitHub dark mode)
- Primary accent: cyan (#00b4d8) for system/infrastructure elements
- Secondary accent: purple (#9d4edd) for AI/memory elements
- Warning color: yellow (#ffd60a) for alerts
- Success color: green (#06d6a0) for confirmations
- All text: white or light gray, monospace font for technical labels
- No gradients, no photorealism, no human figures
